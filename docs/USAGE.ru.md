# Инструкция по использованию

Приложение превращает публичную ссылку на компонент EasyEDA в файлы для Fusion 360
и KiCad. Ниже — полный путь: от поиска детали в библиотеке EasyEDA до готового
компонента в библиотеке Fusion.

---

## Что понадобится

- Windows 10/11 (64-бит).
- Интернет — компонент скачивается с сервера EasyEDA.
- Распакованная папка `EasyEDA2KiCad` с файлом `EasyEDA2KiCad.exe`.

Ни Python, ни KiCad, ни аккаунт EasyEDA для работы не нужны.

---

## Шаг 1. Найдите компонент в библиотеке EasyEDA

1. Откройте EasyEDA и войдите в редактор.
2. Откройте библиотеку компонентов (панель **Library** / **Библиотека**).
3. Найдите деталь по названию, корпусу или LCSC-номеру.
4. Нажмите на компонент, чтобы открыть его карточку, и нажмите кнопку
   **Info** / **i** (информация о компоненте).

Откроется страница компонента в браузере — та самая, где видны символ, футпринт
и 3D-превью.

> Подходят и компоненты сообщества, у которых нет LCSC-номера. Главное, чтобы
> страница компонента была публичной.

---

## Шаг 2. Скопируйте ссылку

Скопируйте адрес страницы из адресной строки браузера. Он выглядит так:

```
https://easyeda.com/component/0123456789abcdef0123456789abcdef
```

Нужен именно адрес страницы компонента. Ссылки на LCSC или JLCPCB
(`.../C12345.html`) этому приложению не подходят — ему нужен UUID EasyEDA.

Если скопировать ссылку и сразу запустить приложение, оно само подставит её
из буфера обмена.

---

## Шаг 3. Конвертируйте

1. Запустите `EasyEDA2KiCad.exe`.
2. Вставьте ссылку в поле **«Ссылка на компонент»** (или нажмите **Вставить**).
3. Выберите папку **«Куда сохранять»**.
4. Проверьте галочки:
   - **Символ** — `.kicad_sym`;
   - **Футпринт** — `.kicad_mod`;
   - **3D-модель** — `.step` и `.wrl`, если у компонента она есть.
5. Нажмите **Конвертировать**.

В журнале появится отчёт: что найдено, что создано и какие предупреждения есть.
Кнопка **«Открыть папку»** откроет результат в проводнике.

### Что появится в папке

```
<имя>_<uuid8>/
├── <имя>.kicad_sym                  ← символ
├── <имя>.pretty/
│   └── <имя>.kicad_mod              ← футпринт
└── <имя>.3dshapes/
    ├── <модель>.step                ← 3D для Fusion
    └── <модель>.wrl                 ← 3D для KiCad
```

Если 3D-модели у компонента нет, папка `.3dshapes` не создаётся, а в журнале
будет предупреждение.

---

## Шаг 4. Импорт в Fusion 360

Это главный шаг. Порядок импорта важен: **сначала футпринт, потом символ**.
Тогда Fusion сам связывает их друг с другом.

1. Откройте Fusion 360.
2. Откройте **Library Manager** (менеджер библиотек) и создайте новую библиотеку
   или откройте существующую.
3. Нажмите **Import** (Импорт).
4. Выберите файл **`.kicad_mod`** (футпринт) из папки `.pretty`.
5. Нажмите **Import** ещё раз и выберите файл **`.kicad_sym`** (символ).
6. Fusion сопоставит символ с футпринтом по полю `Footprint` — в библиотеке
   появится готовый компонент (Device) с уже привязанным корпусом.

Если символ и футпринт не связались:

- проверьте, что оба файла импортированы **в одну и ту же библиотеку**;
- удалите оба элемента и повторите импорт в правильном порядке: `.kicad_mod`,
  затем `.kicad_sym`;
- в крайнем случае создайте Device вручную: вкладка **Devices** → **Create New
  Device** → добавить символ, футпринт и (при наличии) 3D-пакет.

После импорта компонент можно ставить на схему и плату как обычный.

---

## Шаг 5. 3D-модель в Fusion (если нужна)

Fusion не привязывает STEP к футпринту автоматически — это ограничение самого
Fusion. Если файл `.step` есть, добавьте его вручную (четыре клика):

1. **Data Panel** → **Upload** → загрузите файл `.step` в проект.
2. В библиотеке откройте вкладку **Footprints**.
3. Правой кнопкой по нужному футпринту → **Create New 3D Model**.
4. В открывшемся окне: **Data Panel** → правой кнопкой по STEP →
   **Insert into current design**.
5. Выровняйте модель по футпринту, нажмите **Finish** и сохраните библиотеку.

Файл `.wrl` для Fusion не нужен — он только для красивого 3D-просмотра в KiCad.

---

## Если вы работаете в KiCad

KiCad хранит символ и футпринт в разных библиотеках, а связь между ними — это
поле `Footprint` в символе. Приложение его уже заполняет.

1. `Preferences → Manage Symbol Libraries` → добавьте файл `.kicad_sym`.
2. `Preferences → Manage Footprint Libraries` → добавьте папку `.pretty`.
   **Никнейм библиотеки оставьте равным имени папки** — иначе ссылка из символа
   не найдётся.
3. Поставьте символ в схему.
4. `Tools → Update PCB from Schematic` (**F8**) — футпринт появится на плате.

Футпринт не появляется в самой схеме — это нормально, он всегда живёт на PCB.
Если F8 пишет «Footprint not found», откройте символ в Symbol Editor, проверьте
поле `Footprint` и либо переименуйте библиотеку под него, либо назначьте
футпринт заново через `Tools → Assign Footprints`.

---

## Обновление компонента

Чтобы перегенерировать деталь, просто сконвертируйте её ещё раз в ту же папку:
файлы перезапишутся. Если компонент уже добавлен в библиотеку Fusion, импортируйте
новые файлы поверх или удалите старые элементы библиотеки.

---

## Частые проблемы

| Симптом | Причина | Что делать |
|---|---|---|
| «В ссылке нет UUID компонента» | Ссылка не на карточку компонента | Откройте карточку в EasyEDA и скопируйте адрес из браузера |
| «Компонент не найден (404)» | Компонент приватный или удалён | Проверьте, что страница открывается в браузере без входа в аккаунт |
| «Нет 3D-модели» | Автор не прикрепил модель | Возьмите STEP у производителя детали или нарисуйте корпус-заглушку |
| «Только футпринт» | В EasyEDA это отдельный футпринт, а не устройство | Это нормально: символ для него не создаётся |
| В Fusion символ без футпринта | Импортировали символ первым | Удалите оба элемента, импортируйте `.kicad_mod`, затем `.kicad_sym` |
| В Fusion «пустой» компонент | Файлы попали в разные библиотеки | Импортируйте оба файла в одну библиотеку |
| КиКад: «Footprint not found» | Никнейм библиотеки не совпадает | Переименуйте библиотеку или назначьте футпринт заново |
| SmartScreen: «Windows защитила ваш компьютер» | Программа без цифровой подписи | «Подробнее» → «Выполнить в любом случае» |
| Антивирус ругается | Ложное срабатывание на упакованный `.exe` | Добавьте папку в исключения или соберите из исходников |
| Долго скачивается | STEP-модель весит несколько мегабайт | Подождите, журнал покажет прогресс |

---

## Куда приложение пишет настройки

Последняя ссылка, папка и галочки сохраняются в:

```
%LOCALAPPDATA%\EasyEDA2KiCad\config.json
```

Удалите этот файл, если хотите сбросить настройки.
